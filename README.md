💜 Velora – Fashion E-commerce Website

Velora is a modern **full-stack fashion e-commerce web application** designed with a premium UI and smooth shopping experience.

---

🚀 Features

- 🛍️ Product listing with categories  
- 🔍 Search functionality  
- 📄 Product detail page  
- 🛒 Add to cart system  
- ❤️ Wishlist feature  
- 🎨 Glassmorphism UI design  
- 📱 Fully responsive  
- 🔐 User authentication (Login / Signup)  
- ⚙️ Backend integration using Django  

---

🛠️ Tech Stack

🎨 Frontend
- HTML  
- CSS (Glassmorphism UI)  
- JavaScript  

⚙️ Backend
- Python  
- Django  
- SQLite (default database)

---

🔄 User Flow

Home → Product → Detail Page → Cart / Wishlist → Checkout (future scope)

---
💡 Highlights

- Clean UI/UX design  
- Real-world shopping flow  
- Frontend + Backend integration  
- Scalable architecture using Django  

---

⚙️ How to Run the Project 

Step 1: Start Django Backend:
        Terminal 1.Copy and paste this to start your Django server:
> python manage.py runserver

Step 2: Run index.html page (live server)
